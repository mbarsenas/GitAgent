# Architecture Decision Records

GitAgent uses Architecture Decision Records (ADRs) to preserve the reasoning behind durable technical and product choices.

Create an ADR when a change materially affects architecture, security boundaries, data ownership, runtime behavior, provider strategy, permission semantics, storage, networking, deployment, or another decision likely to matter months later.

## Format

Each ADR should contain:

- Title
- Status
- Date
- Context
- Decision
- Consequences
- Alternatives considered

## Status values

- Proposed
- Accepted
- Superseded
- Rejected
- Deprecated
